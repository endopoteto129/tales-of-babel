# テイルズ オブ バベル（試作版）

社内コンペ用の試作 JRPG です。Godot 4（4.3〜4.5.1で動作確認）で作っています。

主人公たちがバベルの塔を一層ずつ昇っていきます。各層のマップは分岐ルートになっていて、戦闘、ショップ、イベント、焚火、ボスのマスがあります。物語は層ごとに進み、仲間との掛け合い（スキット、焚火の語らい、戦闘中のショートチャット）がたくさん入っています。

## 起動方法

1. Godot 4.3 以降（標準版）を用意します。4.5.1 で動作確認済みです。
2. Godot を起動し、「インポート」からこのフォルダの `project.godot` を選びます。
3. F5（またはエディタ右上の ▶）で実行します。

画像や音のアセットは使っていません。キャラクター、背景、エフェクトはすべてコードで描いています。効果音も実行時に合成しています。外部ファイルはフォント（Noto Sans JP、OFL ライセンス）だけです。

## 操作

| 場面 | 操作 |
|---|---|
| バトル | 移動 A/D・←→、通常攻撃 J、術技 K（↑/↓/←→と組み合わせて4種）、ジャンプ Space、ガード L（ガード中に←→でステップ） |
| バトル | ターゲット切替 Tab、共鳴秘技 U（絆ゲージが満タンのとき）、仲間に術技を指示 1/2/3、ポーズ Esc |
| バトル | オーバーリミッツ I（OVLゲージが満タンのとき）、秘奥義 オーバーリミッツ中に I（秘奥義ゲージ100%以上） |
| マップ | ←→でルート選択、決定で進む、スキット T、メニュー M |
| 会話 | 決定で次へ、Esc でスキップ |

ゲームパッド（Xbox配置。PlayStationは同じ位置のボタン）：移動 左スティック/十字キー、攻撃 X(□)、術技 B(○)、ジャンプ A(×)、ガード LB/LT、ターゲット RB、共鳴秘技 RT、オーバーリミッツ／秘奥義 Y(△)、仲間に指示 右スティック←↑→、メニュー START、スキット BACK。

画面に出るボタン表示は、最後に触った入力（キーボードかゲームパッド）に合わせて自動で切り替わります。

## デバッグモード

タイトルの「デバッグ：層を選んで始める」から、各層の「開始」か「ボス直前」へ飛べます（ブラウザ版でも使えます）。「OVL・秘奥義ゲージを満タンにする」にチェックを入れると、毎戦闘ゲージ満タンで始まるので秘奥義を試せます。レベル、スキルツリー、仲間、称号、所持品、レシピは、通常プレイでその時点に想定される状態にそろえます。

## ゲームの中身

- **バトル（LMBS 風リアルタイム）**
  - 横一列の戦場で、通常攻撃 → 特技 → 奥義 → 秘奥義とキャンセルでつなぎます。
  - 仲間3人はAIで共闘します。同じ敵を叩くと「連携」になり、絆ゲージがたまります。
  - 絆ゲージが満タンになると、レンとランダムな仲間1人の合体技「共鳴秘技」を撃てます。
  - OVLゲージが満タンのときにオーバーリミッツ（10秒）。その間はTPを消費せず、のけぞりません。
  - オーバーリミッツ中に秘奥義ゲージ（戦闘をまたいで300%までたまる）を使って秘奥義を放てます。100%でレンの単独秘奥義、200%でレン＋仲間1人、300%でレン＋仲間2人の合体秘奥義（仲間はランダム）。
  - ボスや強敵には装甲があり、割るとブレイク（3.5秒）。ブレイク明けは装甲が全快し、しばらく割れません。のけぞり続けた敵は「踏ん張り」で抜け出すので、無限に固めることはできません。大技の前には予兆が出ます。
- **塔の層（全7層）**
  - スレイ・ザ・スパイア風の分岐マップです。層の途中に強制ストーリーマスがあります。
  - 層に入るたびに「加護」を1つ選びます。加護はその層の間だけ有効で、ローグライク的な強化です（18種）。強敵を倒すと追加で選べます。
- **成長**
  - レベルアップで得た SP でスキルツリーを伸ばします（5人分）。
  - 称号は着け替えると能力が上がります。
- **仲間との交流**
  - 本編ストーリー（序章、全7層、エピローグ）
  - マップ上のスキット 33本
  - 焚火の語らい 20本と、料理の会話
  - 戦闘中のショートチャット 約300パターン（開始、ピンチ、連携、撃破、ボス戦、戦闘中のかけあい、オーバーリミッツ、秘奥義など）
  - 物語が進むと、ポッツの口調やナインの様子が変わっていきます。
- **焚火**：休む、料理する（得意な仲間が作ると効果アップ）、語らう、から選べます。
- **ショップ / イベント**：道具、層限定の加護の護符、レシピを売っています。イベントは18種あり、仲間によって選択肢が変わります。

## フォルダ構成

```
data/        ゲームデータ（キャラ、術技、敵、層、加護、アイテム、称号、スキルツリー、ストーリー、スキット、チャット、イベント、共鳴秘技）
scripts/
  autoload/  DB（データ参照）、Game（進行状態・セーブ）、Sfx（効果音合成）
  battle/    バトル（戦闘キャラ、AI、弾、範囲攻撃、HUD、背景、ナインとポッツ）
  screens/   タイトル、マップ、焚火、ショップ、イベント、メニュー、ゲームオーバー、エンディング
  ui/        共通UI、立ち絵、会話プレイヤー
  validate.gd  データ整合性チェック
```

会話やバランスの調整は、`data/` 以下のファイルを書き換えるだけでできます。

## テスト

```
godot --headless --path . -- --autotest                   # 全画面と全層の戦闘をAIで自動実行
godot --headless --path . -- --autotest --validate-only   # 会話・イベントデータの整合性チェックのみ
godot --headless --path . -- --balance                    # 各層を想定状態にして雑魚・強敵・ボスをAIで対戦し、所要時間と残りHPを表示
godot --headless --path . -- --balance --mystic           # 各層のボスに秘奥義（単独・2人・3人）を撃ち、削れるHPの割合を表示
```
