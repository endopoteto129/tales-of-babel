- 画像の置き場所：`assets/pixel/` の下（`tiles/` `field/` `battle/` `battle_bg/` `fx/`）

## 最初に読むもの
1. `assets/pixel/SPEC.md`：素材の一覧、ファイル名、大きさ、コマの並び、足元の位置、作る順番。**これが正式な仕様です。** 書かれていないことは勝手に決めず、迷ったら報告に書いてください。
2. 見た目の参考：
   - `scripts/battle/fighter_art.gd`（バトルのキャラと敵）と `scripts/field/field_art.gd`（マップのタイル、キャラ、敵シンボル、各層の色）は、今の図形の絵を描いているコードです。髪や服の色、武器、敵の形、各層の配色はここから読み取って、同じ印象のまま描いてください。
   - `assets/portraits/ren/`：レンの立ち絵です。ドット絵の顔立ちや服装はこれに合わせてください。
   - `data/characters.gd`、`data/enemies.gd`、`data/story.gd`：キャラ、敵、各層の設定です。

## 絵柄
- 16bit時代（スーパーファミコン期）のJRPG風。『テイルズ オブ エターニア』のフィールドやバトルを思わせる、明るく読みやすいドット絵にしてください。特定の作品のキャラやドットをそのまま写すのは禁止です。
- 1ドットの暗い色の輪郭線をつけます。光は左上から当たるものとします。
- 同じキャラは、マップ用（16×24）とバトル用（48×48）で同じ配色を使ってください。
- エフェクト（`fx/`）は白から灰色だけで描きます。属性の色はゲームが上から乗せます。

## 作り方の決まり
- 指定の大きさで、1ドットずつ描いてください。大きく描いた絵や生成した画像を縮めるだけ、という作り方はしないでください。画像生成を下絵に使う場合は、指定の大きさに落としたあと色を減らし、ふちの半透明を消して、1ドット単位で手直ししてください。
- PNGは透明背景のRGBAで保存します。半透明のドットやアンチエイリアスは使いません（バトル背景だけは透明なしで構いません）。
- コマは左から右へすき間なく並べます。キャラの足の裏は、すべてのコマで「コマの下端の左右中央」にそろえてください。走りや攻撃で体の位置がぶれると、ゲーム中でキャラが震えて見えます。
- バトルのキャラと敵シンボルは右向きで描きます。マップを歩くキャラだけ4方向を描きます。
- 後から直せるように、各素材を作ったスクリプトや下書き（PythonとPillowでドットを置くスクリプト、パレット定義など）を `art_src/pixel/src/` に残してください。

3. 確認が取れたら、作る順番の2から5まで、順に進めてください。各段階の終わりで報告をお願いします。

## できたら必ず確認すること
- プロジェクトの場所で `python art_src/pixel/check_pixel.py` を実行し、作ったファイルが全部 OK になることを確認してください（Pillowが必要です：`pip install pillow`）。NG が出たら直してから報告してください。
- 確認用に、作った画像を4倍に拡大し（最近傍法、ぼかしなし）、コマの区切りがわかる見本を `art_src/pixel/preview/` に保存してください。バトルのキャラは行ごとに、何の動きかわかるように並べてください。
- Godotがあれば、プロジェクトを開いて第一層を歩き、戦闘に入って、足元のずれや向きがおかしくないか見てください。
