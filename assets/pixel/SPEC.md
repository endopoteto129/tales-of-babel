# テイルズオブバベル ドット絵素材リスト・対応表

この表のとおりに画像を作って `assets/pixel/` に置くと、ゲームが自動でドット絵に差し替えます。ファイルがない物は今の図形の絵のまま動くので、1枚ずつ、できた順に置いて大丈夫です。 立ち絵とスチルは対象外です（今までどおり `assets/portraits/` と `assets/stills/`）。

## 1. 共通のルール（AIに必ず伝えること）

| 項目 | 決まり |
|---|---|
| 基準の解像度 | 画面全体が 320×180ドット。ゲームは1ドットを4×4ピクセルに拡大して表示する（ぼかしなし） |
| 形式 | PNG、背景は透明（RGBA）。半透明のふち・アンチエイリアスは使わない |
| サイズ | 下の表の「1コマ」の大きさちょうどで描く。後から拡大・縮小しない |
| コマの並べ方 | 左から右へ横に並べる。行がある物は上から下へ。すき間（余白）なし |
| 足元の位置 | キャラの足の裏を コマの下端・左右中央 に合わせる（全コマ同じ位置） |
| 向き | バトルと敵シンボルは 右向き で描く（左向きはゲームが反転）。マップを歩くキャラだけ4方向を描く |
| 輪郭 | 1ドットの暗い色の輪郭線をつける（背景に埋もれないように） |
| エフェクトの色 | 斬撃・魔法などのエフェクトは 白〜灰色 で描く。属性の色（火は赤など）はゲームが上から乗せる |
| 置いた後 | Godotでプロジェクトを開くと自動で取り込まれる。ブラウザ版への反映はClaudeが行う。できたら `python art_src/pixel/check_pixel.py` で検査する |

## 7. ドット絵にしない物

- 立ち絵・スチル（高解像度のまま）
- 文字・メニュー・ゲージ・ダメージの数字（読みやすさのため今のまま）
- ボスの大技の予告（ジャンプ・盾のアイコン）、2.5Dの床の赤い予告、詠唱の魔法陣（遊びに直結する目印なので図形のまま）

## 8. 作る順番のおすすめ

1. 第一層ひとそろい：`field/chara_ren`、`tiles/grass`、`field/sym_slime`・`sym_bat`・`sym_wolf`・`sym_golem`、宝箱・焚火・イベント、`field/boss_beast`
2. バトルの主役：`battle/ren`、第一層の敵4種、`battle/boss_beast`、`battle_bg/grass`、`fx/spark`
3. 仲間4人、ナイン、ポッツ
4. 第二層以降のタイル・敵・背景を層の順に
5. 残りのエフェクト

1が置けた時点で、第一層を通して見た目を確認できます。
